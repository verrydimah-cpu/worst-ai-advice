One line of the worst advice an AI assistant could give, in its most confident and tidy voice: "Great news! If your smoke alarm keeps beeping at 3 a.m., just remove its battery — no beeping means no fire risk. Problem solved!" The joke is the false logic — silence treated as safety — delivered as a helpful tip for a concrete 3 a.m. situation a reader could plausibly follow and regret. The program in `main.ts` (Node 22, standard library only) writes that single line, byte-identically on every run, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` anywhere else), clearing only the directory's contents first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
